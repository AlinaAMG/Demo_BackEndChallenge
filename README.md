# Simpele Chat App met WebSockets

Dit is een eenvoudige chat-applicatie die gebruikmaakt van WebSockets om real-time berichtenuitwisseling mogelijk te maken tussen meerdere gebruikers. De applicatie is gebouwd met **Node.js**, **Express.js** en **Socket.io**.

## Gebruikte Technologieën
 
Node.js – JavaScript runtime voor server-side development.
Java Script - voor client-side development
Css 3 - voor styling 
Express.js – Web framework voor Node.js.
Socket.io – Library voor real-time, bidirectionele communicatie tussen web clients en server.


## Functionaliteiten
Real-time chat: Verzend en ontvang berichten direct via WebSockets.
Multi-user ondersteuning: Meerdere gebruikers kunnen tegelijkertijd in dezelfde chatroom actief zijn.
Eenvoudige interface: Een simpele en overzichtelijke gebruikersinterface om berichten te verzenden en ontvangen.
